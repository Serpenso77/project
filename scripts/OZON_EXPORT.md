# Выгрузка каталога Lemashki из Ozon

Скрипт `scripts/export_ozon.py` предназначен для полного сохранения **данных собственного товарного каталога, которые возвращают выбранные методы Ozon Seller API**. Это не обход блокировок публичного сайта. Все запросы только читают данные: цены, остатки и товары в кабинете не изменяются. Заказы, покупатели, отзывы, финансовые отчёты и содержимое, которое Ozon не отдаёт этими методами, не входят в выгрузку.

## Что сохраняется

- Все страницы списка товаров с видимостью ALL, включая архивные товары, если API их возвращает.
- Внутренние product_id, артикулы offer_id, SKU и все поля ответов об информации товаров.
- Полные описания, атрибуты и их значения, rich-content, комплектация, упаковка и доступные размеры/составы — **если эти поля возвращены API**, без выдумывания пропусков.
- Все поля методов цен и остатков. Для полной детализации по всем складам и отчётам могут понадобиться другие методы API.
- Дерево категорий и справочники атрибутов используемых категорий/типов.
- Все обнаруженные ссылки на медиа, включая вложенный JSON rich-content.
- Оригиналы изображений, видео и PDF на доступных CDN Ozon. Внешние ссылки сохраняются отдельно; ролики в сторонних плеерах, потоковые манифесты и ссылки на страницы не скачиваются как видеофайлы.
- Исходные ответы API и даты их получения; объединённый JSON и CSV.

## Требования и запуск

Python 3.10+; сторонние библиотеки не нужны. Получите Client ID и ключ с разрешениями чтения каталога, характеристик, цен и остатков в своём кабинете Ozon Seller. При необходимости выдайте права на справочники категорий. Не включайте разрешения изменения товаров ради этой выгрузки.

Добавьте через защищённые настройки среды:

- `OZON_CLIENT_ID`
- `OZON_API_KEY`

Не отправляйте ключи в чат, не вставляйте в исходники, URL или аргументы команд. Не выводите значения переменных в логи. Если запускаете на своём компьютере, задавайте их средствами защищённой конфигурации вашей системы.

```sh
cd /workspace/project
python3 scripts/export_ozon.py
```

Либо `npm run export:ozon`. Скрипт без ключей завершится с понятной ошибкой до сетевых запросов.

Для выгрузки только данных и ссылок без файлов:

```sh
python3 scripts/export_ozon.py --skip-media
```

Повтор той же команды продолжает работу, используя сохранённые ответы и проверенные SHA-256 файлов. Это возобновление прежней выгрузки, а не обновление цен. Чтобы получить свежие данные:

```sh
python3 scripts/export_ozon.py --refresh
```

Для независимого снимка или другого аккаунта:

```sh
python3 scripts/export_ozon.py --output .data/ozon-export-new
```

Каталог привязывается к хешу Client ID: использовать его с другим кабинетом нельзя. Ключ не сохраняется. Каталог `public/` запрещён для выгрузки. Не публикуйте исходные ответы и CSV: они могут содержать внутренние товарные/ценовые данные продавца.

## Результат

По умолчанию `.data/ozon-export/` (исключён из Git):

| Файл / каталог | Содержимое |
| --- | --- |
| `manifest.json` | Статус, ошибки, пропуски, предупреждения, даты и методы |
| `products.json` | Все полученные поля каждого товара, сгруппированные по источнику |
| `products.csv` | Основные поля для просмотра, полное описание, ссылки, JSON цен и остатков |
| `dictionaries.json` | Дерево категорий и названия характеристик |
| `raw/` | Исходные ответы API с запросами без заголовков авторизации |
| `media/` | Скачанные оригиналы с безопасными именами |
| `media-index.json` | URL, путь, MIME, размер и SHA-256; контроль целостности при повторе |
| `media-files.json` | Файлы, доступные в текущем запуске |
| `external-links.json` | Внешние ссылки, которые не скачиваются автоматически |
| `account.json` | Только SHA-256 Client ID для разделения кабинетов |

`products.json` — основной формат без обрезания полей. CSV имеет фиксированные столбцы для удобного просмотра и не заменяет исходные JSON. Формулоподобные значения в CSV экранируются; исходный текст сохраняется точно в JSON.

Статусы:

- `complete`: предусмотренные этапы завершились без ошибок. Проверьте предупреждения и `missing_records`: API может не возвращать цену/остаток архивного товара. Это не обещание выгрузки абсолютно всех данных, хранящихся внутри Ozon.
- `metadata_only`: данные и ссылки сохранены, файлы намеренно пропущены (`--skip-media`).
- `partial`: один или несколько этапов/файлов не получены. Код завершения 1, ошибки не скрываются.
- `failed`: авторизация или другая критичная ошибка. Успешные промежуточные ответы сохраняются для повтора.

Ошибки 401/403 останавливают работу без бесконечных повторов. Для 429 и временных серверных/сетевых ошибок API предусмотрено до четырёх попыток с задержкой. Повторяющиеся курсоры, полные страницы без курсора и досрочное окончание списка при известном total считаются ошибкой, а не успешной полной выгрузкой. Файлы крупнее 100 МиБ по умолчанию не скачиваются и отмечаются ошибкой; лимит можно изменить через `--max-media-mb` (1–2048).

Если товар не возвращён методами информации/атрибутов, это ошибка полноты. Пустые цена/остаток не заменяются нулями; такие товары перечислены в `missing_records`. При изменении API точный проблемный метод указан в отчёте; версии централизованы в `ENDPOINTS`. Скрипт не делает запись даже при использовании HTTP POST: здесь POST применяется только к методам чтения Ozon.

Чтобы передать выгрузку для последующего импорта, архивируйте всю папку средствами вашей ОС. При передаче только `products.json` фотографии придётся скачивать повторно. Сам экспортёр не меняет текущий каталог сайта. Для публикации подготовленного снимка служит `scripts/import_ozon_catalog.py`: он требует завершённую выгрузку, объединяет только точные seller SKU и сохраняет исходные описания/цены обеих площадок; остальные варианты добавляет отдельно.

## Проверки и текущие ограничения

```sh
npm run test:ozon
```

Автотесты проверяют несколько страниц, полные описания, частичные ошибки, курсоры, API-кеш и обновление, повтор после 429, немедленный отказ после 401, разграничение аккаунтов, сбор медиа из rich-content, разрешённые хосты, MIME/подпись/хеш и возобновление скачивания. Автотесты используют тестовые ответы, без обращения к вашему кабинету. Дополнительно выполнен живой экспорт, описанный ниже.

На момент создания проверено, что `api-seller.ozon.ru` доступен и без авторизации отвечает 401. 23.10.2026 выполнен живой авторизованный экспорт кабинета: все 30 товаров, описания, атрибуты, цены и остатки получены без пропусков; скачаны 175 фотографий и 14 видео. Все используемые версии методов отработали. Отчёт `.data/ozon-export-live/manifest.json` имеет статус `complete`. Для другого кабинета и последующих обновлений проверяйте новый отчёт; при изменении API корректируется соответствующий метод без потери сохранённых исходных ответов.

Ozon не предоставляет транзакционный снимок всего каталога между этими запросами: на время экспорта желательно не менять товары. При возобновлении сравнивайте даты ответов в манифесте; для целиком свежего запуска используйте новую выходную папку.

Для временных сетевых ошибок скачивания медиа, включая DNS, выполняются до трёх попыток. Постоянные ошибки, неподдерживаемый MIME и неверные подписи файлов не скрываются.
